BRIGHT FUTURE TECHNOLOGIES APPLICATION

This project is a simple Java product management system. It allows the user to capture, search, update, delete, and view products using a menu.

Features

- Capture a new product.
- Search for a product using the product code.
- Update product warranty, price, and stock level.
- Delete a product.
- Print a product report.
- Calculate total product value and average product value.
- Exit the application.

Language and Concepts Used

Programming Language: Java

Concepts used:

- "Scanner" for user input.
- Classes and objects.
- Constructors.
- Getters and setters.
- Arrays for storing products.
- "while" loops.
- "for" loops.
- "if/else" statements.
- "switch" statements.
- Methods and method calls.
- Encapsulation.

Usage

1. Open the project in NetBeans.
2. Run "JavaApplication11".
3. Enter 1 to open the menu.
4. Select an option from 1 to 6.
5. Follow the instructions shown on the screen.

Challenges and Wishes

Challenges

This was solved by using methods, loops, conditions, and an array to manage the products.
